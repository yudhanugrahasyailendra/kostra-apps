## Brand & Style

This design system is engineered for modern boarding house (*kost*) management in Indonesia, serving both property owners managing multiple units and tenants accessing frictionless billing links. The visual personality is grounded, trustworthy, systematic, and hospitable. It balances SaaS operational precision with domestic warmth.

### Visual Style
The design system combines **Corporate Modern** with **Soft Tactility**. Instead of harsh, cold enterprise dashboards, it uses a soft cream-tinted canvas paired with architectural deep teal and refined ochre accents. High-contrast typography, crisp containment borders, and restrained elevation create order ("Rapi") across complex inventory grids, WhatsApp receipt previews, and payment trackers.

### Emotional Goals
- **Clarity & Trust:** Instant legibility for financial balances, room occupancies, and overdue notices.
- **Frictionless Simplicity:** Low-cognitive-load layouts for tenants opening bill links on mobile networks down to 360px widths.
- **Professional Dignity:** Empowering owners with polished tools that elevate their boarding house business.

## Colors

The palette draws directly from architectural materiality: patinated copper, polished brass, lime wash, and warm paper.

### Palette Roles
- **Primary (`#0F5A57`):** Deep Pine Teal. Anchors primary actions, brand headers, active navigation pills, and verified markers.
- **Secondary (`#D99B26`):** Warm Ochre / Amber Gold. Applied sparingly to highlight attention states, premium tags, active room selections, and pending reminders.
- **Tertiary (`#2B3A42`):** Slate Iron. Provides deep contrast for structural headers, table headers, and high-emphasis data points.
- **Neutral (`#6B7280`):** Balanced Cool Gray. Used for non-interactive icons, descriptive metadata, and supportive divider scales.

### Functional Status Indicators
Room states and payment transactions use strict semantic pairings that maintain a minimum of 4.5:1 contrast against their soft tinted backgrounds:
- **Lunas (Paid / Occupied):** Green emerald (`#065F46` text on `#ECFDF5` surface).
- **Menunggu (Pending Verification):** Warm amber (`#92400E` text on `#FEF3C7` surface).
- **Jatuh Tempo (Overdue / Urgent):** Rose crimson (`#9F1239` text on `#FFE4E6` surface).
- **Kosong (Vacant Room):** Neutral slate (`#374151` text on `#F3F4F6` surface).

## Typography

The type system relies completely on **Plus Jakarta Sans**, a modern geometric grotesque designed with humanist legibility cues. It guarantees sharp rendition on mobile screens and low-resolution cellular connections.

### Typographic Hierarchy
- **Currency & Figures:** Indonesian Rupiah amounts (`Rp 1.500.000`) use `currency-display` or `title-lg` with tight numerical spacing and tabular alignment flags when rendered in data tables or bill breakdowns.
- **Headlines:** Display and Headline roles use semi-bold and bold weights with subtle negative tracking (`-0.01em` to `-0.02em`) to ensure punchy, compact titles.
- **Form Labels & Table Cells:** Form field headings use `label-md`, while subtext hints use `body-sm` in secondary charcoal to maintain distinct contrast.

## Layout & Spacing

The layout model adapts to two core use cases: the multi-property admin workspace (desktop and tablet) and the tenant quick-view link (narrow mobile viewports down to 360px).

### Grid & Structure
- **Desktop (1024px+):** Fluid 12-column grid with a fixed collapsible left navigation rail (240px wide). Maximum content container capped at `1280px` for optimal tabular data scanning. Gutters sit at `1.5rem` (`24px`).
- **Tablet (768px - 1023px):** 8-column layout with `1rem` (`16px`) gutters and collapsible drawer navigation.
- **Mobile (360px - 767px):** 4-column layout with `1rem` outer canvas padding. Full-width cards stack vertically with zero horizontal scroll requirements.

### Spacing Rhythm
Built strictly on a **4px base unit** (0.25rem increments):
- Use `space-xs` (4px) and `space-sm` (8px) for tightly coupled items: badge padding, button icon gaps, table cell vertical paddings.
- Use `space-md` (16px) for interior card body padding, form input heights, and stack gaps.
- Use `space-lg` (24px) for dashboard widget separators and modal section padding.
- Use `space-xl` (32px) and `space-2xl` (48px) for major layout segment separators.

## Elevation & Depth

Visual hierarchy is maintained primarily through **surface layering and low-contrast outlines**, backed by warm, ambient shadows.

### Tonal Surface Hierarchy
1. **Canvas (`bg-canvas` / `#FBFBFA`):** The master page background. Provides a gentle, anti-fatigue cream tint.
2. **Surface Level 1 (`bg-surface` / `#FFFFFF`):** High-level operational cards, tables, bill containers, and modal sheets.
3. **Surface Level 2 (`bg-subtle` / `#F4F5F6`):** Secondary groupings, table header strips, input backgrounds, and inactive room cards.

### Shadow Architecture
Shadows feature warm neutral undertones rather than generic cold black tints:
- **Flat / Outline:** `border: 1px solid #E5E7EB; box-shadow: none;` (Default for data grid rows, filter bars, and inactive cards).
- **Elevation Low (Resting Cards):** `0 1px 3px 0 rgba(17, 24, 39, 0.05), 0 1px 2px -1px rgba(17, 24, 39, 0.05)`.
- **Elevation Mid (Dropdowns & Hover States):** `0 4px 6px -1px rgba(17, 24, 39, 0.07), 0 2px 4px -2px rgba(17, 24, 39, 0.05)`.
- **Elevation High (Modals & Resident Action Sheets):** `0 20px 25px -5px rgba(15, 90, 87, 0.08), 0 8px 10px -6px rgba(17, 24, 39, 0.04)`.

## Shapes

The system uses `roundedness: 2` (base `0.5rem` / `8px`). This creates a friendly yet structured feel, matching the architectural identity of the house motif in the logo.

### Application Rules
- **Base Components (Inputs, Buttons, Badges, Table Rows):** `rounded-md` (`0.5rem` / `8px`).
- **Containers & Cards (Room Cards, Invoice Panels, Modal Dialogs):** `rounded-lg` (`1rem` / `16px`).
- **Interactive Badges & Status Pills:** Fully rounded (`9999px` / capsule shape) to clearly distinguish them from actionable rectangular buttons.
- **Borders:** Consistent `1px` stroke width across all card outlines, dividers, and default input borders.

## Components

### Buttons
- **Primary Button:** Background `#0F5A57`, text `#FFFFFF`, border none, hover background `#0D4A47`, active scale `98%`. Border radius `8px`. Height `40px` (desktop), `44px` (mobile touch target).
- **Secondary Button:** Background `#FFFFFF`, text `#0F5A57`, border `1px solid #0F5A57`. Hover background `#F0FDF4`.
- **Accent Button (Remind / Bayar):** Background `#D99B26`, text `#FFFFFF`. Used for high-intent conversion actions (e.g., "Kirim Tagihan WhatsApp", "Konfirmasi Pembayaran").
- **Ghost Button:** Background transparent, text `#4B5563`, hover background `#F4F5F6`.

### Badges & Status Chips
- Rendered in pill shape (`rounded-full`) with `label-sm` typography (uppercase, bold, tracking `0.03em`).
- Padding: `4px 10px`.
- Combinations:
  - **Lunas:** Text `#065F46`, background `#ECFDF5`, border `1px solid #A7F3D0`.
  - **Menunggu:** Text `#92400E`, background `#FEF3C7`, border `1px solid #FDE68A`.
  - **Jatuh Tempo:** Text `#9F1239`, background `#FFE4E6`, border `1px solid #FECDD3`.
  - **Kosong:** Text `#374151`, background `#F3F4F6`, border `1px solid #E5E7EB`.

### Form Fields & Inputs
- **Base Input:** Height `42px`, padding `8px 12px`, background `#FFFFFF`, border `1px solid #D1D5DB`, radius `8px`, typography `body-md`. Focus state uses border `#0F5A57` with an ambient glow ring (`box-shadow: 0 0 0 3px rgba(15, 90, 87, 0.15)`).
- **Currency Input (Rupiah):** Prefix slot containing static `Rp` in `#6B7280` on subtle `#F4F5F6` background, seamlessly joined with the numeric text entry.

### Cards & Room Grid Units
- **Room Unit Card (Kost Grid):**
  - Dimensions: flexible minimum width `160px`.
  - Container: White background with `1px solid #E5E7EB`, radius `12px`, padding `16px`.
  - Top row: Room identifier (e.g., "Kamar 102") in `title-md` and status chip.
  - Middle: Tenant name in `body-sm` (`text-secondary`) or "Kosong" placeholder.
  - Bottom: Rate in `currency-display` (16px) with billing cycle indicator.
  - Hover: Subtle outline change to `#0F5A57` and Elevation Mid shadow.

### Tenant Tokenized Bill View (Mobile Portal)
- Single-column centered card (max width `440px`) on canvas `#FBFBFA`.
- Prominent header displaying the Kostra house mark, Kost property name, and invoice month.
- Summary block with large currency figure (`display-lg-mobile`) and clear status banner.
- Direct sticky action button at card footer: "Upload Bukti Transfer" or "Bayar via QRIS".

### Checkboxes & Radio Buttons
- Checkbox: `18px` by `18px`, radius `4px`. Inactive border `#D1D5DB`, checked state background `#0F5A57` with white checkmark icon.
- Radio: Circular `18px`, active state features `#0F5A57` outer rim with a `6px` solid center dot.
